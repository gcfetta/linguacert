# 🌍 LinguaCert - Plataforma de Práctica y Certificación de Idiomas Web3

LinguaCert es una aplicación descentralizada (DApp) diseñada para revolucionar el aprendizaje y la validación de competencias lingüísticas mediante la combinación de Inteligencia Artificial y tecnología Blockchain.

## 🚀 Características Principales
- **Autenticación Web3 Segura:** Inicio de sesión criptográfico nativo mediante la vinculación directa de MetaMask.
- **Tutoría Interactiva por IA:** Generación dinámica de debates y correcciones gramaticales personalizadas en tiempo real consumiendo Gemini 2.5 Flash.
- **Certificación Inmutable:** Registro indeleble e infalsificable de logros académicos directamente en la Testnet de Sepolia.

## 🛠️ Stack Tecnológico & Líneas del Programa Aplicadas
- **Frontend & Backend:** Next.js 16 (Turbopack) con TypeScript (Aplicación de Sistemas de Tipos Estrictos).
- **Inteligencia Artificial:** Modelos conversacionales avanzados mediante OpenRouter API (Gemini 2.5 Flash).
- **Blockchain & Smart Contracts:** Solidity v0.8.19 e integración Web3 mediante Ethers.js.

## 🔧 Instrucciones de Instalación Local
1. Clonar el repositorio.
2. Ejecutar `npm install` para instalar las dependencias (incluyendo `lucide-react` y `ethers`).
3. Configurar la clave `sk-or-...` en las llamadas del backend.
4. Levantar el entorno de desarrollo usando `npm run dev`.
